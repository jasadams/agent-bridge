## Fixes

- Show friendly agent aliases or native session titles on board message inputs in
  both terminal and web viewers. Generated registration IDs no longer appear as
  the default name. Meaningful authored labels or concise provider names are used
  when friendly metadata is unavailable.
- Refresh names without losing drafts or caret position. Labels remain tied to
  the exact recipient session; a replacement session cannot inherit an old draft.
- Keep sends quiet: no routine sending or success message expands the composer.
  Successful acceptance clears the input. Errors and uncertain outcomes remain
  visible when they need attention.

## Upgrade

Run `agent-bridge update`, then reconnect the MCP server or restart agent clients
to load the updated executable. Reload an existing web board once to load the new
interface, or restart the terminal board viewer.

Replies sent to `user` appear in the same bridge's Messages view or
`agent-bridge history --agent user`; they are not displayed inside the board input.

This patch adds no public tool API change or database migration over v0.3.3.
See the versioned [board guide](https://github.com/jasadams/agent-bridge/blob/v0.3.4/docs/board.md)
for controls and message delivery behavior.
