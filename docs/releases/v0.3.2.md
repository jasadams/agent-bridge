## Changes

- Subscribe to board changes and local agent availability with the unified
  `subscribe` and `unsubscribe` tools, including `agent.opened` and `agent.closed`
  events for coordinators.
- Message an agent directly from a reusable input on the terminal or web board.
  Enter submits, drafts survive live updates, and retries preserve message identity.
  Shift+Enter adds a newline in the browser; Ctrl-J is the terminal alternative.
- Show broker-maintained Last Updated metadata in both board footers, using the
  viewer's timezone and daylight-saving rules. Reads, no-op edits and sending a
  board message do not advance the content timestamp.
- Copy inline code and code blocks from both board viewers. Web checkboxes render
  inline, and ordinary text responses appear in place with Save/Cancel.
- Discover new local boards automatically in the web dropdown without refreshing
  the page or disturbing the selected board, focus or drafts.
- Archive and restore named boards through the terminal, web, CLI and MCP.
  Archives retain exact content for 30 days, then broker-owned cleanup permanently
  deletes them. Main is protected. Retention continues while viewers are closed,
  with startup catch-up and retryable recovery after interrupted operations.
- Deliver messages to active Codex sessions using verified native capabilities
  and protocol responses instead of an exact Codex version allowlist. Ambiguous
  native writes retain the existing no-replay protection.
- Keep board backing-file paths out of normal agent responses, including replies
  forwarded from an older broker. User-authored Markdown paths remain unchanged.
  Agent guidance requires revision-checked broker tools for board edits.
- Reduce repeated peer-message instructions and repair bounded plugin-test cleanup
  and browser test synchronization without weakening production delivery limits.

## Upgrade and integration updates

Run `agent-bridge update`, then reconnect the MCP server or restart agent clients
to load the executable and updated tool definitions. If using OpenCode, refresh
the plugin with `agent-bridge opencode install` using the same configuration/state
options as the original setup, then fully restart the affected OpenCode instances.

Integrations must use `subscribe`/`unsubscribe` instead of the removed board-only
subscription tools. Named-board selectors require the current `board_revisions`
map; read the board before subscribing or selectively unsubscribing. Subscriptions
remain opt-in and must be re-established after broker restart or board restoration.

Board clients must use logical names and revisions rather than a response `path`
field. On conflict, review the returned current snapshot and preserve other writers'
changes. If broker tools are unavailable, report the blocker rather than editing
backing files directly. This does not add an OS sandbox or prevent independent
same-user filesystem discovery.

Back up state before upgrading: the database upgrades automatically, and older
binaries must not open the migrated database. Archive is reversible only before
its persisted 30-day deadline. External backups are outside automatic cleanup.
Archive file-identity checks fail safely on filesystems that cannot provide the
required birth-time metadata; ordinary board reads remain available.
