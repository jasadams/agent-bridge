## Fixes and refinements

- Use overlapping-sheets copy icons for inline code and code blocks in both
  terminal and web boards. Successful web copying briefly shows a checkmark in
  the same-sized button, without shifting the board. Accessible announcements
  and visible clipboard errors remain available.
- Keep compact agent message inputs pinned below the board in both viewers.
  Multiple inputs stack with friendly agent names and Send buttons, while the
  board scrolls independently above them.
- Click or tab directly into terminal message inputs without an extra Enter
  activation step. Clicking Send dispatches immediately without a later keypress.
  Remove routine composer instructions, technical target rows and unused space.
- Keep focused inputs visible when the web viewport resizes or the input stack
  overflows. Preserve drafts, caret, exact recipient/session binding and explicit
  handling of stale targets or uncertain submissions.
- Repair private browser catalog fixtures after board responses stopped exposing
  backing-file paths, while retaining external-deletion and navigation coverage.

## Upgrade

Run `agent-bridge update`, then reconnect the MCP server or restart agent clients
to load the updated executable. Reload an existing web board once to load the new
interface, or restart the terminal board viewer.

Enter sends a message. Shift+Enter adds a newline in the web input; Ctrl-J is the
terminal alternative. Replies sent to `user` appear in the same bridge's Messages
view or `agent-bridge history --agent user`; they are not an inline conversation
inside the board input.

This patch adds no public tool API change or database migration over v0.3.2.
See the versioned [board guide](https://github.com/jasadams/agent-bridge/blob/v0.3.3/docs/board.md)
for keyboard controls and message delivery behavior.
